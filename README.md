# William-Year-9-Space-Invaders-CT-Assessment

**This is only for Windows**

## Description:
In Space Invaders, you control a spaceship and your goal is to attack the aliens.
## How to install

1. Go to the Releases on this GitHub Repository
2. Click on the ZIP File to install the folder with the game
3. Extract the ZIP File
4. Go to the Dist Folder
5. Go to the Main Folder
6. Open up main.py
7. Enjoy!

## Controls
A: Move Left
D: Move Right
SPACE: Shoot
